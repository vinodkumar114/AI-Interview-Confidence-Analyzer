# AI-Powered Virtual HR Interview System & Confidence Analyzer

Live interactive platform designed to evaluate candidate communication, technical responses, fluency, and eye contact in real time.

## 🔗 Live Links
* **Live Website:** [https://ai-interview-confidence-analyzer.vercel.app](https://ai-interview-confidence-analyzer.vercel.app)
* **Backend API Docs:** [https://ai-interview-confidence-analyzer.onrender.com/docs](https://ai-interview-confidence-analyzer.onrender.com/docs)

## 🚀 Key Features
* Real-time video and gaze/eye contact tracking
* Audio fluency, pause detection, and speech-to-text transcript analysis
* Automated technical response scoring with ideal benchmark answers
* Instant PDF assessment download and direct email report dispatch

## 🛠️ Tech Stack
* **Frontend:** React, Vite, Tailwind CSS
* **Backend:** FastAPI, Python, SQLite, ReportLab
* **Hosting:** Vercel (Frontend), Render (Backend)
